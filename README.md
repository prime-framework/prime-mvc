## Prime MVC - Internal

This is an internal repository for publishing Prime MVC security Updates.

This repo should be brought up to date with the latest changes from the public repo [here](https://github.com/prime-framework/prime-mvc) before patching.

### Patch Prime MVC Internally

The publish repo in this project is set up to push to the internal savant repository (https://internal.svn.fusionauth.io). The Savant Release target will
push the changes to the internal repository. Once pushed it is available for all FusionAuth prime-mvc dependent services:
- FusionAuth App
- FusionAuth Reactor
- FusionAuth Account
- FusionAuth Stats
- Clean Speak
